# Data

This directory contains the datasets used for the Engineering College
Placement & Recruitment Intelligence project.

## Dataset Overview

The final analytical dataset contains:

- 22,386 records
- 20 analytical variables
- 2,813 engineering colleges
- 33 standardized states
- 7 engineering branches
- 4 institutional tiers

## Data Sources

The project dataset was collected through web scraping from government
official websites and subsequently processed and standardized for analysis.

## Dataset Versions

### Raw Data

Raw collected data should be stored separately and should not be modified
directly.

### Processed Data

The processed analytical dataset is used for Python analysis and Power BI.

## Important Note

The analytical dataset contains both quantitative indicators and
descriptive text fields related to curriculum, recruiter requirements,
skills and emerging technologies.
