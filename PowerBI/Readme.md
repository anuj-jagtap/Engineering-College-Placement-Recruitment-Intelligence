# Power BI Dashboards

The project contains four interactive Power BI dashboards.

## Dashboard 1
### Engineering College Placement & Recruitment Intelligence

Focus:

- Overall performance
- Branch performance
- Tier comparison
- Salary
- Employability
- Internship participation

---

## Dashboard 2
### Recruiter Readiness & Shortlisting Intelligence

Focus:

- Recruiter demand
- Placement vs employability
- Missing skills
- Recruiter-ready institutions

---

## Dashboard 3
### Recruiter Shortlisting & College Comparison

Focus:

- Recruiter readiness
- College comparison
- Placement performance
- Multidimensional filtering

---

## Dashboard 4
### State & Institutional Performance Analysis

Focus:

- State performance
- Institutional category
- Ownership
- Salary
- Employability
- Recruiter opportunity

## Filters

The dashboards support interactive analysis using dimensions such as:

- Tier
- State
- Branch
- Ownership
- Category
- College
